# Как показать многоагентную систему другому человеку

На текущем компьютере дважды нажмите `examples/show_demo.cmd`. Скрипт использует
готовую `.venv`, запускает небольшой synthetic пример и открывает HTML в браузере.
Все три сценария действительно выполняются через существующие агенты; модель
обучается один раз явно в примере, затем используется для inference.

То же из PowerShell:

```powershell
cd D:\DeceptionDetection
.venv/Scripts/python.exe examples/multi_agent_demo.py --open
```

`--open` включает создание презентации. Без открытия браузера используйте
`--present`. Каждый запуск создаёт новый `outputs/agent-demo-<UUID>/`; путь к
`presentation.html` печатается в консоли. Браузер открывает локальный файл,
сервер и интернет для показа не нужны. Подготовленный HTML можно открыть
двойным кликом и передать другому человеку одним файлом: для просмотра не
нужны Python, модель, исходный CSV или остальные JSON.

На другом компьютере повторное **вычисление** требует установки обычного
окружения проекта по README; для просмотра готового HTML это не требуется.
Если автоматическое открытие браузера не сработало, откройте напечатанный HTML вручную.

## Сценарий объяснения на 3–5 минут

1. Скажите: «Это демонстрация архитектуры анализа айтрекинга на синтетических
   данных. Класс предсказывает сохранённая ML-модель, агенты управляют этапами».
2. Выберите **1. Нормальный сигнал** и нажмите **Показать по шагам**. Покажите
   последовательность Acquisition → Quality → Features → Prediction → Verification
   → Report. Для объяснения можно нажать паузу или двигаться кнопкой **Следующий шаг**.
3. На конечном экране сравните время накопления окна и время model service,
   покажите вероятности искусственных классов, признаки и журнал. Объясните:
   **COMPLETED** означает выполненный pipeline; **INCONCLUSIVE** — отсутствие
   оснований принять научное решение без утверждённого порога.
4. Покажите распределение: 14 agent/tool calls, максимум 21.43% у FeatureExtractionAgent.
   Это распределение количества вызовов, а не доля CPU или независимых участников.
5. Переключите **2. Отказ: плохой сигнал**. Нажмите **Все результаты**:
   Quality REJECTED, признаки/предсказание не выданы, причина сохранена в отчёте.
6. Переключите **3. Отказ: ошибка модели**: несоответствие checksum вызывает
   контролируемый FAILED; приложение сохраняет журнал и report.
7. При необходимости нажмите **Скачать отчёт** для machine-readable JSON.
   Кнопка активна после завершения показа выбранного сценария.

Показ представляет сохранённый журнал реального выполнения offline workflow.
Анимация замедлена для объяснения и не измеряет скорость вычислений, не подаёт
новые samples и не является physical live/replay engine. По кнопке просмотра
HTML не переобучает и не вызывает модель заново; новый расчёт запускает команда Python.

## Что показывается и что остаётся за рамками

Demo использует существующий Logistic Regression baseline, train/test participants
разделены, predictor не получает истинных labels. LSTM/TCN inference поддерживается
основным агентным слоем и отдельно проверен тестами; эта презентация не называет
baseline нейросетью. Сырые samples не встраиваются в HTML: только отчёты, агрегированные
признаки, журнал, статистика и provenance синтетического запуска.

Научная accuracy реальных truth/lie, причинная обработка и физический айтрекер
пока не подтверждены. Техническую архитектуру можно демонстрировать сейчас;
результат нельзя представлять как установленный детектор лжи.

Устройство системы и запуск с реальными разрешёнными файлами описаны в
[MULTI_AGENT_ARCHITECTURE_RU.md](MULTI_AGENT_ARCHITECTURE_RU.md).
